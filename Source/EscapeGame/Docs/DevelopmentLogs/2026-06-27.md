### 纠错与解释

本轮重点纠正了一个概念：

```text
GameplayTag 不是进度本身。
GameplayTag 是“这是谁 / 查哪条记录”的 Key。
RuntimeState 里的字段才是会变化的状态。
```

例如：

```cpp
QuestRuntimeMap[QuestID].ObjectiveStates[ObjectiveID].CurrentCount
```

含义是：

```text
先用 QuestID 找到任务状态，
再用 ObjectiveID 找到目标状态，
最后读写 CurrentCount / bCompleted 等变化字段。
```

### 学到的东西

- `DialogueRuntimeMap` 的 Key 是 `DialogueID`。
- `VisitedOptionIDs` 是某段对话内部的历史记录，不是外层 Map 的 Key。
- `ActiveSession.CurrentNodeID` 决定当前 UI 下一次应显示哪个节点。
- `FDialogueRuntimeState.CurrentNodeID` 记录这段对话长期状态中最近到达的节点。
- `SelectOption` 是后续 `EvaluateCondition`、`ApplyEffect`、UI、任务、存档的基础切片。
