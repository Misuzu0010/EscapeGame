# Development Logs

本目录用于记录学习型开发过程中的每日进展。

约定：

- 每一天一个 Markdown 文件。
- 文件名使用 `YYYY-MM-DD.md`。
- 新记录追加到当天文件顶部或按时间顺序补在当天章节中。
- 日志不仅记录“做了什么”，也记录“为什么这样做、遇到什么问题、如何纠错、学到了什么、下一步是什么”。

推荐模板：

```md
## HH:mm - 阶段名称

### 本阶段目标

### 学习目标

### 已完成内容

### 修改文件

### 执行命令

### 验证结果

### 遇到的问题

### 纠错与解释

### 学到的东西

### 仍然不理解的问题

### 下一步建议
```
